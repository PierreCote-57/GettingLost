# WP title and date model

Learned 2026-07-11 debugging howto-power on the live site (gettinglostonvi.wpcomstaging.com).

## Browser-tab / document title
- The `<title>` is generated by WP core `wp_get_document_title()` (Twenty Twenty-Five
  supports `title-tag`). Format: `{post_title} – {Site Title}`, e.g.
  "Power management – Getting Lost in Canada".
- `post_title` comes from the per-page JSON **`"name"`** field (sync.js sets
  `body.title = pageData.name` — renamed from `"title"` in schema-unification Phase
  3a, 2026-07-20). This is SEPARATE from the on-page `<h2>` heading in the HTML body
  (they can differ; power page: tab "Power management" vs heading "Managing power").
- The " – Getting Lost in Canada" suffix is the **Site Title** (WP Settings →
  General) + separator, appended by core. It is NOT in the Site Editor templates
  or the repo — so it can't be edited as a template.
- To drop the suffix site-wide: PHP filter
  `add_filter('document_title_parts', fn($p) => (unset($p['site'],$p['tagline'])) ?: $p)`
  (unset `site` + `tagline`). Needs a code home — a code-snippets plugin (WPCode /
  Code Snippets) or a small custom/mu-plugin. Pierre asked how on 2026-07-11 but
  had not done it yet.

## Post dates
- Footer "Last modified" uses `<!-- wp:post-date {"displayType":"modified",...} /-->`.
  Without `displayType:"modified"` it silently shows the PUBLISH date instead.
- A `wp:post-date` block must be a real block — nesting it inside raw HTML/`<span>`
  makes it inert (renders blank). It needs post context (resolves on singular
  post/page views).
- `post_modified` = the sync time (WP auto-stamps on every update; sync.js sends no
  date for pages). Confirmed via REST that sync DOES bump it; a stale footer was a
  render/caching artifact, not a sync bug.
- `post_date` (published): for POSTS, sync sets it from the JSON **`"date"`** field
  ([sync.js](local/sync/sync.js) ~L565) so Pierre can backdate posts and typo-fixes
  don't move it. PAGES send no date. There is no per-post timezone in WP (only
  site-wide); post_date/post_date_gmt store local+UTC but not the zone name.
