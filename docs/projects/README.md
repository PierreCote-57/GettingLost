# Projects

One file per project, and this index carries its status. **Status lives here and nowhere
else** — a project's own file describes the work as it stands now, with no "phase 3 done",
no "pending", no account of how it got there. That narration is what rots; the file outlives
it.

When a project completes: mark it complete here, then strip the status and history out of
its file, leaving only what is true about the thing that now exists.

completion date because it is not a finished project, it is a running part of the site.
